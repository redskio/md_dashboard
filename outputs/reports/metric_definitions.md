| # | 항목 | **확정값** | 근거 |
|---|---|---|---|
| **D1** | 취소 행 처리 | **행을 유지하고 수량을 차감**한다 (`수량 − canceled_qty`) | 부분취소 `OI00005158`(수량 2, 취소 1)은 행 제외로 처리할 수 없다. README 매출 정의도 수량 차감식이다 |
| **D3** | 쿠폰할인액 배부 | **유효수량 비율로 안분** — `쿠폰할인액 × (수량−canceled_qty) ÷ 수량` | README가 "쿠폰할인액의 **유효수량 배부**"라고 명시. **데이터로는 두 방식을 구분할 수 없다** — 쿠폰 있는 취소 31건이 전부 수량 1, 부분취소 1건은 쿠폰 0원. **현재 데이터에서 결과 차이는 0원** |

| **D5** | 환불금액 예외 4건 | **원본 값을 그대로 사용**하고 리포트에 각주로 표기 | `RT000277`·`RT000316`·`RT000372`·`RT000378`이 쿠폰할인액의 절반만 차감. 410건 중 4건(1%)이고, 값 수정은 데이터 처리 규칙 위반 |

## 2. 지표 정의

### 2-1. 유효판매수량

| 항목 | 내용 |
|---|---|
| **지표명** | 유효판매수량 (Effective Sold Qty) |
| **업무 질문** | 취소를 뺀 실제 판매 수량은 얼마인가 |
| **계산식** | `SUM(수량 − canceled_qty)` |
| **분석 단위** | SKU / 상품 / 카테고리 (`order_item` 기준) |
| **기준일** | 2026-07-31 |
| **집계 기간** | 2026-02-01 ~ 2026-07-31 (시즌 전체) 또는 지정 구간 |
| **포함·제외 조건** | 전 행 포함. 취소는 행 제외가 아니라 수량 차감 (D1) |
| **분모 0 처리** | 해당 없음 |
| **원천** | `order_item.수량`, `order_item.canceled_qty` |
| **검증식** | 전체 기간 = 9,114 − 213 = **8,901** (취소 205건 212개 + 부분취소 1건 1개). 음수 발생 시 오류 |
| **해석 제한** | 수량 값이 1(8,548) / 2(283)뿐이라 수량 기반 구매 패턴 해석 불가 |

### 2-2. 순판매수량

| 항목 | 내용 |
|---|---|
| **지표명** | 순판매수량 (Net Sold Qty) |
| **업무 질문** | 반품까지 빼고 최종적으로 팔린 수량은 얼마인가 |
| **계산식** | `유효판매수량 − SUM(완료 반품수량)` |
| **분석 단위** | SKU / 상품 / 카테고리 |
| **기준일** | 2026-07-31 |
| **집계 기간** | 지정 구간 (재고주수 계산 시 2026-07-04~07-31) |
| **포함·제외 조건** | `처리상태='완료'` **AND `처리일 ≤ 2026-07-31`** 만 차감 (D2). 접수 32건과 기준일 이후 처리 7건 제외 |
| **분모 0 처리** | 해당 없음 |
| **원천** | `order_item.수량`, `canceled_qty`; `returns.반품수량`, `처리상태`, `처리일` |
| **검증식** | 전체 기간 = 8,901 − **371** = **8,530**. 순판매수량 ≤ 유효판매수량 |
| **해석 제한** | `재판매가능='N'` 반품은 재고로 돌아오지 않아 재고 수량과 어긋날 수 있음 |

### 2-3. 순매출

| 항목 | 내용 |
|---|---|
| **지표명** | 순매출 (Net Revenue) |
| **업무 질문** | 실제로 인식할 매출은 얼마인가 |
| **계산식** | `판매단가 × (수량 − canceled_qty)`<br>` − 쿠폰할인액 × (수량 − canceled_qty) ÷ 수량`<br>` − 완료 반품 환불금액` |
| **분석 단위** | 상품·카테고리·SKU → `order_item` / 전사·채널 → 주문 합산 |
| **기준일** | 2026-07-31 |
| **집계 기간** | 지정 구간 (기본 시즌 전체) |
| **포함·제외 조건** | `상품할인액`은 **차감하지 않는다** — 이미 `판매단가`에 반영 (D4). 환불 예외 4건은 원본 값 사용 (D5) |
| **분모 0 처리** | 해당 없음 |
| **원천** | `order_item.판매단가`, `수량`, `canceled_qty`, `쿠폰할인액`; `returns.환불금액`, `처리상태`, `처리일` |
| **검증식** | ① 순매출 ≤ `SUM(판매단가×수량)` = 522,451,800 ② 상품·카테고리 합계 = 전사 합계 ③ 주문 단위 합산값 = `order_item` 단위 합산값 |
| **해석 제한** | 쿠폰코드와 쿠폰할인액이 불일치(코드 있는데 할인 0: 803주문 / 코드 없는데 할인 발생: 1,350주문)하여 **쿠폰코드 기준 매출 귀속 불가** |

| 항목 | 내용 |
|---|---|
| **지표명** | 최근 28일 판매속도 (Weekly Sales Velocity) |
| **업무 질문** | 지금 속도로 팔면 주당 몇 개가 나가는가 |
| **계산식** | `최근 28일 순판매수량 ÷ 4` (D12) |
| **분석 단위** | SKU (재고주수 계산용) / 상품 |
| **기준일** | 2026-07-31 |
| **집계 기간** | **2026-07-04 ~ 2026-07-31** (기준일 포함, 28일) (D11) |
| **포함·제외 조건** | 분자는 순판매수량 — 반품 차감 (D12). 주문일시 기준으로 기간 필터 |
| **분모 0 처리** | 고정 분모 4이므로 해당 없음 |
| **원천** | `order_item`, `orders.주문일시`, `returns` |
| **검증식** | 판매속도 ≥ 0. 28일 합계 = 주차별 4주 합계 |
| **해석 제한** | 시즌 중간이라 **7월 판매속도를 연간 평균으로 해석 금지.** `시즌민감도='높음'` 카테고리는 28일 창이 짧을 수 있음 |

### 2-7. 재고주수 (WoS)

| 항목 | 내용 |
|---|---|
| **지표명** | 재고주수 (Weeks of Supply) |
| **업무 질문** | 지금 재고로 몇 주를 버티는가 |
| **계산식** | `기준일 available_qty ÷ 최근 28일 판매속도` |
| **분석 단위** | SKU (정책 판정 단위) → 상품·카테고리로 집계 |
| **기준일** | **2026-07-31 스냅샷** (399 SKU 전량, `available_qty` 합 12,664) |
| **집계 기간** | 재고는 시점값, 분모는 2026-07-04~07-31 |
| **포함·제외 조건** | 가용재고 = `available_qty` 단독 (D13) |
| **분모 0 처리** | **판매속도 0이면 미산출(빈값) + 「무판매」 구간으로 분류** (D14). 무한대·캡 금지 |
| **원천** | `inventory_snapshot.available_qty`, `snapshot_date`, `sku_id` |
| **검증식** | ① 기준일 스냅샷 행 수 = 399 ② `on_hand = available + reserved + damaged` (12,366/12,369 성립, 예외 3행) ③ 재고주수 ≥ 0 |
| **해석 제한** | 스냅샷 간격 불균등(주 1회 + 월말) → **주간 추세 비교 시 간격 보정 필요.** `in_transit_qty`가 전 행 0이라 **입고 예정 물량 반영 불가** |

### 2-8. 정책 초과 여부

| 항목 | 내용 |
|---|---|
| **지표명** | 정책 초과 여부 (Policy Breach Flag) |
| **업무 질문** | 이 재고 수준은 정상인가, 소진 대상인가, 리오더 대상인가 |
| **계산식** | 우선순위 순서로 판정 (D15)<br>① **무판매** — 판매속도 = 0<br>② **소진 대상** — `WoS ≥ clearance_point_wos`<br>③ **리오더 대상** — `WoS ≤ reorder_point_wos`<br>④ **정상** — `target_wos_min ≤ WoS ≤ target_wos_max`<br>⑤ **주의** — 위 어디에도 속하지 않는 구간 |
| **분석 단위** | SKU (판정) → 상품·카테고리 (집계) |
| **기준일** | 2026-07-31 |
| **집계 기간** | 시점 판정 |
| **포함·제외 조건** | 경계값 포함 (D15). 리오더 판정은 산출하되 **"발주 중단 상태" 표기 병기** (D16) |
| **분모 0 처리** | 무판매 SKU는 ①로 분류 (D14) |
| **원천** | `inventory_policy.target_wos_min/max`, `reorder_point_wos`, `clearance_point_wos`; `category_master.시즌민감도` |
| **검증식** | ① 5개 분류 SKU 수 합 = **399** ② 소진·리오더 동시 판정 0건 ③ 정책 커버리지 = 19개 카테고리 전부 |
| **해석 제한** | 원본 README가 **"정책 테이블은 교육용 승인 기준이며 정답이 아님"** 이라고 명시. 판정은 **액션 후보**이지 지시가 아니다. **정책 구간에 빈틈이 있어 「주의」로 빠지는 SKU가 생긴다** — 예: 임계값 (14/32/8/44) 카테고리에서 WoS가 9~13 또는 33~43이면 어느 분류에도 해당하지 않는다. 임계값 ±1주 민감도를 함께 본다 |

## 3. 지표 간 의존 관계

```
유효판매수량 ─┬─→ 순판매수량 ─┬─→ 최근 28일 판매속도 ─→ 재고주수 ─→ 정책 초과 여부
              │                └─→ 반품률
              └─→ 순매출 ─→ 가용 공헌이익
```

상류가 바뀌면 하류가 전부 바뀐다. 결정을 변경할 경우 이 순서로 재계산한다.
