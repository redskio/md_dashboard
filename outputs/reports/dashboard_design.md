# 대시보드 설계서 — 차트 구성과 모니터링 목적

- **대상 지표**: 지표 정의서 8개 (유효판매수량, 순판매수량, 순매출, 가용 공헌이익, 반품률, 최근 28일 판매속도, 재고주수, 정책 초과 여부)
- **원천**: `data/marts/` 5종. **대시보드는 계산하지 않고 마트를 읽기만 한다** (CLAUDE.md 코드 원칙)
- **분석 기준일**: 2026-07-31 고정
- **구현 스택**: Streamlit + Plotly

> 이 문서는 **차트 형태를 먼저 정하고 색을 마지막에 정한다.**
> 색은 눈으로 판단하지 않고 검증기로 계산한 결과를 근거로 삼는다.

## 0. 설계 원칙 (전 차트 공통)

| 원칙 | 내용 |
|---|---|
| **이중축 금지** | 하나의 플롯에 y축 2개를 두지 않는다. 두 스케일의 정렬은 임의여서 **없는 상관관계를 만들어낸다.** 매출과 재고처럼 단위가 다른 지표는 **세로로 쌓은 별도 차트(x축 공유)** 로 그린다 |
| **색은 대상을 따른다** | 필터로 계열이 빠져도 남은 계열의 색은 바뀌지 않는다. "여성=파랑"을 학습한 사용자가 오해하지 않도록 |
| **명목 범주에 값 램프 금지** | 상품·카테고리처럼 순서가 없는 범주를 "크면 진하게" 칠하지 않는다. 막대 길이가 이미 그 정보를 담고 있다 |
| **모든 점에 숫자 금지** | 범례는 2계열 이상이면 항상 두고, 직접 라벨은 **끝점·극단값만** 선택적으로 |
| **상태색은 예약** | 정책 판정 같은 상태 표현에만 쓰고, 일반 계열 색으로 재사용하지 않는다. **아이콘 + 라벨을 항상 동반**한다 |
| **분모 병기** | 모든 비율 옆에 건수를 함께 표시한다 (소표본 오독 방지) |
| **얇은 마크** | 실선 hairline 그리드, 2px 선, 마커 8px 이상, 채움 사이 2px 간격 |

### 색 검증 결과 (계산으로 확인)

**카테고리 6색** (대분류: 여성·남성·아동·장비·용품·스킨케어) — 슬롯 고정 순서

| 슬롯 | 대분류 | Light | Dark |
|---|---|---|---|
| 1 | 여성 | `#2a78d6` | `#3987e5` |
| 2 | 남성 | `#eb6834` | `#d95926` |
| 3 | 아동 | `#1baf7a` | `#199e70` |
| 4 | 장비 | `#eda100` | `#c98500` |
| 5 | 용품 | `#e87ba4` | `#d55181` |
| 6 | 스킨케어 | `#008300` | `#008300` |

- Light: **전 항목 통과.** 색각 이상 최저 인접쌍 ΔE 9.1, 정상 시야 19.6
- Dark: **전 항목 통과.** ΔE 8.4 / 19.3
- Light 모드에서 3색(아쿠아·옐로·마젠타)이 배경 대비 3:1 미만 → **직접 라벨과 표 보기(table view)를 필수**로 둔다

**정책 판정 5색은 상태색으로 쓰되, 색만으로 구분시키지 않는다.**
검증기를 돌린 결과 `주의(#fab219)`와 `소진(#ec835a)`의 정상 시야 ΔE가 **13.6으로 기준선 15 미만**이었다. 두 색이 맞닿는 형태(누적 막대)를 쓰지 않고, **분리된 막대 + 아이콘 + 라벨**로 표현한다.

| 판정 | 색 | 아이콘 | 의미 |
|---|---|---|---|
| 리오더 | `#d03b3b` (critical) | ▲ | 품절 위험 — 매출 손실이 즉시 발생 |
| 소진 | `#ec835a` (serious) | ● | 재고 과잉 — 자본이 묶임 |
| 주의 | `#fab219` (warning) | ◆ | 정책 구간 밖 |
| 정상 | `#0ca30c` (good) | — | |
| 무판매 | `#898781` (muted) | ○ | 판매 신호 없음 (재고주수 산출 불가) |

## 1. 화면 A — 재고 건전성 (첫 화면)

**이 화면이 답하는 질문**: 지금 재고에 문제가 있는가, 있다면 돈이 어디에 묶여 있는가.

### A-1. KPI 행 — 스탯 타일 4개

| 항목 | 형태 | 모니터링 내용 |
|---|---|---|
| 전사 재고주수 (31.2주) | **히어로 수치** + 스파크라인 | 재고가 몇 주치인지. 시즌 잔여 기간과 비교해 과부족의 총량을 한눈에 |
| 총 재고금액 (352,263,900원) | 스탯 타일 | 묶여 있는 자본의 규모 |
| 소진 대상 금액·비중 (176,190,100원 / 50.0%) | 스탯 타일 + 미터 | **처분 검토가 필요한 자본의 비중.** 이 화면의 핵심 숫자 |
| 액션 후보 SKU 수 (291 / 399) | 스탯 타일 | 처리해야 할 업무량 |

**왜 차트가 아니라 타일인가**: 값이 하나뿐인 수치는 막대 1개짜리 차트로 그리지 않는다. 숫자 자체가 차트다.

### A-2. 정책 판정별 재고금액 — 가로 막대

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 어느 판정 구간에 자본이 몰려 있는가. 소진 대상이 절반을 차지하는 구조가 유지되는지, 개선되는지 |
| **형태** | 가로 막대 5개 (판정명이 길고 범주가 적음) |
| **색** | **단일 색(슬롯 1) + 판정 아이콘.** 5개 상태색을 나란히 두면 주의·소진이 구분되지 않으므로, 길이로 크기를 읽고 아이콘·라벨로 상태를 읽게 한다 |
| **정렬** | 재고금액 내림차순 |
| **직접 라벨** | 막대 끝에 금액과 비중(%) |
| **원천** | M2 `정책판정`, `inventory_value` |
| **오독 방지** | SKU 수와 금액을 함께 표시. SKU 수는 소진 116 / 정상 108로 비슷하지만 **금액은 2배 차이**라 SKU 수만 보면 문제가 작아 보인다 |

### A-3. 재고주수 분포 — 히스토그램 + 임계선

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 재고주수가 어디에 몰려 있고 정책 임계선을 얼마나 벗어나는가. **정책 구간의 빈틈(「주의」 80건)이 어디서 생기는지** |
| **형태** | 히스토그램 (x=재고주수, y=SKU 수), `reorder`·`target` 구간·`clearance` 위치에 세로 기준선 |
| **색** | 막대는 단일 색. 기준선은 muted ink 실선 hairline (**점선 금지** — 점선은 "예측"으로 읽힌다) |
| **원천** | M2 `재고주수`, `reorder_point_wos`, `target_wos_min/max`, `clearance_point_wos` |
| **오독 방지** | 재고주수 최대가 364주라 **긴 꼬리가 생긴다.** x축 상한을 자르지 말고 로그 스케일 또는 "100주 이상" 묶음 구간을 두고, 잘랐다는 사실을 축에 표기 |
| **주의** | 판매속도 0인 27개 SKU는 재고주수가 **빈값**이라 히스토그램에서 빠진다. "무판매 27건 미포함"을 차트 부제에 명시 |

### A-4. 카테고리 × 판정 — 히트맵

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 재고 문제가 특정 카테고리에 집중돼 있는가. 아동이 매출 대비 재고가 큰 현상이 지속되는지 |
| **형태** | 히트맵 (행=대분류 6, 열=판정 5, 셀=재고금액) |
| **색** | **시퀀셜 단일 색조**(블루 램프, 밝음→어두움). 무지개 램프 금지. 스케일 범례 필수 |
| **원천** | M2 + M3 |
| **오독 방지** | 셀에 금액을 직접 표기(6×5=30셀이라 가능). 색만으로 값을 읽게 하지 않는다 |

### A-5. 임계값 민감도 — 라인

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 소진 대상 116건이라는 숫자가 **얼마나 견고한가.** 정책 임계값을 ±1~5주 움직이면 대상이 몇 건으로 변하는지 |
| **형태** | 라인 1개 (x=임계값 조정폭, y=대상 SKU 수), 현재 값에 마커 강조 |
| **색** | 단일 색 + 현재 지점만 강조(emphasis) |
| **원천** | M2 (조정은 화면에서 계산하지 않고 **사전 산출한 민감도 테이블**을 읽음) |
| **왜 필요한가** | 원본 README가 "정책 테이블은 교육용 승인 기준이며 정답이 아님"이라고 명시했다. 임계값이 결과를 좌우한다면 그 사실이 화면에 보여야 한다 |

## 3. 화면 C — 상품 성과

**이 화면이 답하는 질문**: 어떤 상품이 실제로 돈을 남기는가.

### C-1. 순매출 vs 공헌이익 — 산점도

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | **매출 상위와 이익 상위가 일치하는가.** 매출은 큰데 이익이 안 남는 상품을 찾는 것이 목적 |
| **형태** | 산점도 (x=순매출, y=가용공헌이익, 크기=재고금액), 이익률 기준선 대각선 |
| **색** | 대분류 6색 — **단, 산점도는 3색 상한**이므로 기본은 **단일 색 + 카테고리 필터**로 두고, 비교가 필요할 때만 상위 3개 카테고리를 강조 |
| **직접 라벨** | 상하위 5개 상품 |
| **원천** | M3 |
| **오독 방지** | 소표본 상품은 마커를 **속 빈 원(hollow)** 으로 그려 신뢰도 차이를 형태로 구분 |

### C-2. 카테고리별 순매출·공헌이익 — 그룹 막대

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 카테고리 6개의 매출·이익 기여도. 여성이 매출 47%·이익 48%를 차지하는 구조가 유지되는지 |
| **형태** | 가로 그룹 막대 (카테고리 6 × 지표 2) |
| **색** | 2계열이므로 슬롯 1·2. 범례 필수 |
| **원천** | M3 |
| **오독 방지** | 매출과 이익은 **같은 단위(원)** 이므로 한 축에 그려도 된다. 이익률(%)은 **별도 차트**로 분리 — 단위가 다르므로 같은 플롯에 두지 않는다 |

### C-3. 이익률 하위 상품 — 강조 막대

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 개선 여지가 큰 상품. 현재 **공헌이익 적자 상품은 0개**이므로 "적자 탐지"가 아니라 "이익률 하위 관찰"이 목적 |
| **형태** | 가로 막대 하위 10개 + **전사 평균선(38.6%)** |
| **색** | **강조(emphasis)** — 소표본 경고가 붙은 상품만 accent, 나머지는 회색 |
| **원천** | M3 |
| **오독 방지** | 하위 8개 중 7개가 판매 30개 미만이다. **소표본 배지 없이 이 차트를 보여주면 잘못된 결론으로 직행한다.** 막대 옆에 판매수량을 항상 병기 |

### C-4. 반품률 — 막대 + 분모

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 품질·사이즈 이슈 신호. 전사 4.2% 대비 이탈 상품 |
| **형태** | 가로 막대 (상위 10) + 전사 기준선 |
| **색** | 단일 색 + 기준선 |
| **원천** | M3 `반품률`, `판매자귀책_반품률` |

## 4. 화면 D — 추세

**이 화면이 답하는 질문**: 지금 흐름이 좋아지고 있는가, 나빠지고 있는가.

### D-1. 주별 순매출 — 라인

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 판매가 꺾였는지. 현재 마지막 완전주(07-26)가 26주 중 최고치라 **"재고가 남는 것은 안 팔려서"라는 가설을 반박**하는 근거 |
| **형태** | 라인 1개 (26주) |
| **색** | 단일 색. 1계열이므로 범례 없이 제목이 계열명을 대신한다 |
| **직접 라벨** | 최고점·최저점·마지막 값만 |
| **원천** | M4 (`is_partial_week=False`) |
| **오독 방지** | **마지막 부분주(07-27~07-31, 5일)는 회색 점 하나로 분리 표기**하고 라인에 잇지 않는다. 이으면 급락으로 오독된다 |

### D-2. 주별 재고량 — 라인 (D-1 바로 아래, x축 공유)

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 매출이 오르는데 재고가 함께 줄고 있는가. **매출-재고의 시차 관계** |
| **형태** | 별도 라인 차트. **D-1과 x축을 공유해 세로로 정렬** |
| **왜 이중축이 아닌가** | 매출(원)과 재고(개)는 스케일이 달라 한 플롯에 겹치면 **두 축의 정렬이 임의**가 되어 없는 상관관계를 만들어낸다. 세로 정렬은 같은 시점 비교가 가능하면서 이 왜곡이 없다 |
| **원천** | M4 `available_qty`, `snapshot_used` |
| **오독 방지** | 스냅샷 간격이 불균등(주1회 + 월말)하므로 실제 측정 시점에만 마커를 찍고, 마커 사이는 보간이라는 점을 부제에 명시 |

### D-3. 상품별 WoW 증감 — 다이버징 막대

| 항목 | 내용 |
|---|---|
| **모니터링 내용** | 이번 주에 **갑자기 꺾인 상품 / 튄 상품.** 액션이 필요한 변화 감지 |
| **형태** | 다이버징 가로 막대 (0 기준 좌우), 상하위 각 8개 |
| **색** | **다이버징 2색 + 중립 회색 중간점.** 증가는 따뜻한 색, 감소는 차가운 색. 중간점에 색을 두지 않는다 |
| **원천** | M4 `순매출_WoW` |
| **오독 방지** | 주간 등락이 ±20%로 원래 크다. **단주 변동을 추세로 읽지 않도록** 4주 이동평균 대비 편차 옵션을 함께 제공 |

## 6. 접근성

| 항목 | 규격 |
|---|---|
| 범례 | 2계열 이상이면 **항상** 표시. 4계열 이하는 직접 라벨도 병행 |
| 색 단독 금지 | 정책 판정은 **아이콘 + 라벨** 동반. 소표본은 **형태**(속 빈 마커)로도 구분 |
| 다크 모드 | 자동 반전이 아니라 **다크 전용 색 단계**를 사용 (위 표의 Dark 열, 검증 통과) |
| 텍스트 색 | 값·라벨·범례는 ink 토큰. **계열 색을 글자에 쓰지 않는다** |
| 텍스처 | 기본 꺼둠. 색각 이상·인쇄·`forced-colors` 상황에서만 45°/135° 옵션 |
